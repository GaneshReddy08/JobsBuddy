# 🌍 JobsBuddy

JobsBuddy tracks software, AI, data, cloud and related technology openings in India, plus roles explicitly marked remote worldwide. The public job feeds refresh every two hours. Filter by experience, city, role, company, recency and remote location, or browse startup openings.

Listings come from the public ATS feeds connected in `companies.json` (including Greenhouse, Lever, Ashby, Workday and other supported sources). Recruiter emails are shown only when a posting publishes one. Free and open source.
